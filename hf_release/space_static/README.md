# Multi-agent generative AI with formal verification in Lean 4

Results explorer for a course project (Inteligencia Computacional, UPTC Sogamoso): a multi-agent system
(Planner, Retriever/RAG, Generator, AutoFormalizer, LeanVerifier, Critic) tries to prove 30 miniF2F problems in
Lean 4 / Mathlib, and five configurations are compared. This page only shows saved results.

- Code and reproduction: https://github.com/KimberlyFigueroa21/proyecto_ia_lean (tag `congelado`)
- Authors: Kimberly Natalia Figueroa Zapata, Alisson Páez Alarcón (UPTC Sogamoso)
